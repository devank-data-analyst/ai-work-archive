# AI Work Archive

A curated archive and portfolio of artificial intelligence experiments, practical tools, workflows, and projects.

## Overview

This repository hosts the **AI Fieldnotes** web archive — a living index of experiments, LLM workflows, and intelligent tools built to explore and practicalize modern AI systems.

## Features

- **Project Showcase**: Categorized collection of AI builds, workflows, and research notes.
- **Interactive Filtering**: Filter by build type (`Built with AI`, `Workflow`, `Research & notes`).
- **Clean Responsive Design**: Lightweight, responsive interface styled for clarity and ease of navigation.

## Getting Started

To view the archive locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/devank-data-analyst/ai-work-archive.git
   cd ai-work-archive
   ```
2. Open `index.html` in your browser:
   ```bash
   # Linux
   xdg-open index.html

   # macOS
   open index.html
   ```

## Customization

- Update personal details and links in [index.html](index.html).
- Add new project cards within the `#projects` grid in [index.html](index.html).
